# Kids BJJ Lesson Planner

Random kids-class lesson plans in the same layout as the printed first-class document, plus take-home coloring sheets.

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8765
```

Then go to http://127.0.0.1:8765

Custom warm-ups, lessons, games, and uploaded coloring sheets stay in that browser (localStorage / IndexedDB). They are not stored on GitHub.
